Al Azif is a fictional entity in the Demonbane Mythos. The character was originally created by Jin Haganeya, appearing as one of the main heroines for the visual novel Deus Machina Demonbane.

Key threads from this canonical page lead to Call of Cthulhu, Necronomicon, Cthulhu Mythos and Avatar. Each link is another long-tail path through the subject.
