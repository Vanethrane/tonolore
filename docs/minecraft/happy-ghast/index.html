A happy ghast is a passive mob added in Chase the Skies. Unlike its hostile counterpart, the ghast, it is passive towards players and can be ridden by using a harness. It was revealed in Minecraft Live - March 2025.

Key threads from this canonical page lead to Minecraft, Spawn Egg, Harness, Ghast and Water. Each link is another long-tail path through the subject.
