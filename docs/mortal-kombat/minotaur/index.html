Minotaurs are an unnaturally formed species, created after the Shokan people placed a curse upon the Centaurians, which transformed many of them, like Motaro, into a bipedal race.

Key threads from this canonical page lead to Mortal Kombat, Mortal Kombat: Armageddon, Outworld, Motaro, Shokan and Blaze. Each link is another long-tail path through the subject.
