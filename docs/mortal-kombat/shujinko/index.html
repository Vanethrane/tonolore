Shujinko (Japanese: 主人公) is a character in the Mortal Kombat fighting game series. He made his debut in Mortal Kombat: Deception as the main character and protagonist of Konquest Mode.

Key threads from this canonical page lead to Mortal Kombat, Mortal Kombat: Deception, Shang Tsung, Bo' Rai Cho, Nightwolf and Kung Lao. Each link is another long-tail path through the subject.
