Jet Set and Upper Crust are married upper class unicorns from Canterlot who first appear in Sweet and Elite. The terms "upper crust" and "jet set" refer to high social status.

Key threads from this canonical page lead to My Little Pony, Twilight Sparkle, Fancy Pants, Wonderbolts, Ponies and Rarity. Each link is another long-tail path through the subject.
